Servo Calibrator

Drives an Arduino running ServoCalibrator_Companion.ino over Web Serial and uses an AS5600 encoder as ground truth. Two things it can do, independently: find a servo's real pulse range/travel (to feed into RCServoCalibration.ino by hand later, or save for this tool to finish later), and run the whole installation/calibration wizard itself — the same steps as that sketch, just guided by the encoder instead of eyeballing, ending in a ready-to-paste constructor.

Web Serial isn't available in this browser. This tool needs Chrome or Edge (desktop). If Connect stays greyed out even there, try serving this file over http://localhost instead of opening it directly (e.g. npx serve or python -m http.server in this folder).

4 Range finder

Finds the servo's real minimum/maximum pulse width and total mechanical travel by walking it outward from center until the encoder shows no further movement — the same goal as RCServoRangeFinder.ino, just detected automatically instead of by ear. This is a property of the bare servo, not of any specific installation: do it with the horn free and clearly visible, no linkage, mechanism, gearbox, or load attached (same safety note as that sketch). Once you have a result you can either save it and stop here — to use later with the raw wizard sketch or reload into this tool when you're ready to install the servo — or continue straight into the installation wizard below.

STEP 2 — Logical angle range

Your logical angle range is how your own code will refer to positions — it doesn't have to match the servo's raw 0…travel range. Enter where you want logical zero to sit, as an offset from the servo's physical minimum. Example: on a servo with 180° of travel, entering -90 gives you a logical range of -90°..+90° (a common, intuitive choice — 0 becomes the mechanical center). Entering 0 just uses 0…travel directly.

STEP 3 — Horn installation

Enter the logical angle where you'd like to install the servo horn. This is your best estimate for now — it doesn't need to be exact, you'll fine-tune it in Step 5. A common choice is your logical range's center (prefilled below).

Install the horn so your mechanism/linkage is positioned the way you want at this angle. When ready, continue.

STEP 4 — Direction test

The servo will move a small step away from where you just installed the horn. Watch which way your output (the horn/linkage) actually moves.

Did it move in the direction you consider positive?
STEP 5 — Fine trim (optional)

Align precisely now using whatever reference you're using — witness marks, a pin-drop hole, a mechanical hard stop, etc. Step the servo in small increments (in your chosen positive direction with +, the other way with −) until it's exactly where the angle below should be. Skip this and the calibration offset stays 0 — same as skipping fine trim in RCServoCalibration.ino.
