Universal-Motor-Interface + Universal-Trajectory-Interface companion tool

Servo Calibrator

Purely for characterization: one button finds a servo's real pulse range and builds a 20-point calibration lookup table, fully automated, on-device — no installation wizard, no direction/logical-zero setup (always physical [0, maxAngle], just like the table itself). Building an actual driver constructor from the result is left to your own UMI application code. Once calibrated, drive/visualize a move against it live. This firmware doesn't remember a calibration across a reconnect — recalibrate fresh each session (no GETTABLE/IMPORT on this companion).
